FTC Java Training

Choose a module and build FTC programming fundamentals.

Prerequisites

  • FTC Robot Controller and Driver Station apps installed and paired.
  • Android Studio with FTC SDK project opened and build working.
  • Basic Java syntax knowledge (variables, if statements, loops, methods).
  • A configured robot in the FTC Robot Configuration file.

Required Hardware List

  • Control Hub or Robot Controller phone.
  • Driver Hub or Driver Station phone.
  • At least one gamepad.
  • 1 DC motor (example name: armMotor).
  • 1 servo motor (example name: armServo or clawServo).
  • 12V FTC legal battery and power wiring.
  • USB cable for programming/debugging.
